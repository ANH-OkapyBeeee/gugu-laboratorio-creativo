# GuGu | Laboratorio Creativo®

Sitio web profesional y portafolio de **Alexis Nicolás Hurtado**, Ingeniero en Sistemas Computacionales.

Presenta servicios de desarrollo de software (sitios web, sistemas a la medida, apps y automatización) y los proyectos realizados.

## Tecnologías

- HTML, CSS y JavaScript (sin dependencias)
- Firebase Hosting
- Git y GitHub

## Estructura

```
public/        Sitio (lo que se publica)
firebase.json  Configuración de Firebase Hosting
```

## Ejecutar en local

Abre `public/index.html` en el navegador, o sirve la carpeta:

```bash
npx serve public
```

## Publicar

```bash
firebase deploy --only hosting
```
